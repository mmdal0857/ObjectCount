> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ObjectCount에 `docs/wiki/` 지식 베이스를 시드하고, 전역 컨벤션·housekeeping 린트·에이전트 참조 연결까지 완성한다.

**Architecture:** 경량 플랫 위키(플랫 파일 + 수동 WIKI_INDEX.md). 위키는 코드처럼 브랜치를 따라가며, 코드가 정본이고 위키는 안내판이다. 다른 LLM은 CLAUDE.md/AGENTS.md 포인터와 디스패치 프롬프트의 명시 경로로 참조한다.

**스펙:** `docs/superpowers/specs/2026-07-13-llm-wiki-design.md` (grill 세션 반영판, 커밋 09646a1)

## Global Constraints

- frontmatter는 정확히 3필드: `title`, `summary`, `last_updated`(YYYY-MM-DD)
- 페이지 본문 150줄 상한 — 초과 시 분할이 아니라 압축(세부는 ADR·스펙 링크로 대체)
- non-obvious only: 코드·README가 이미 답하는 내용 복제 금지
- stable/live 분리: 진행 중 태스크·진행률 등 휘발 상태 기록 금지
- 용어는 CONTEXT.md 정본(프로덕트·프로덕트 후보·트랙·카운트라인 — 품종·가상선 금지)
- 전역 파일(`~/.claude/**`)은 git 커밋 대상이 아님. 레포 파일만 커밋
- 커밋 메시지는 기존 스타일(`docs: ...`) + `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`

- **non-obvious only**: 코드·README가 이미 답하는 내용 복제 금지 — 중복 문서는 에이전트 성능을 낮춘다(arXiv 2601.20404)

- **코드가 정본**: 위키·코드 충돌 시 코드가 옳다. 발견한 에이전트는 위키 갱신을 보고한다

## 참조 규칙
- CLAUDE.md·AGENTS.md 핵심 문서 섹션이 `docs/wiki/WIKI_INDEX.md`를 가리킨다
- **디스패치 규칙**: Orca 태스크·Codex 위임·로컬 모델 리뷰 프롬프트 작성자는 관련 위키 페이지 경로를 명시 포함한다. 소형 컨텍스트 모델은 인덱스 탐색 없이 지정 페이지만 읽는다
- 워커 워크트리의 위키는 낡았을 수 있다 — 디스패치 전 `last_updated` 확인, 낡았으면 경로 대신 내용을 직접 프롬프트에 넣는다

## 갱신 규칙
- 위키는 코드처럼 브랜치를 따라가고 병합으로 전파된다
